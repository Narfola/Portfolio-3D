# 🚀 Mon Projet React + TypeScript

Une application web moderne construite avec React, TypeScript et optimisée avec Vite. Le projet intègre également Biome pour un linting et un formatage ultra-rapides.

---

## 🛠️ Technologies utilisées

*   **Framework :** [React 18](https://react.dev/)
*   **Langage :** [TypeScript](https://www.typescriptlang.org/)
*   **Outil de build :** [Vite](https://vitejs.dev/)
*   **Linter & Formatter :** [Biome](https://biomejs.dev/)
